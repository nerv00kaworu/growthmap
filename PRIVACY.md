# GrowthMap Privacy Notice (interim)

> This factual notice has not been reviewed by qualified legal counsel and is not legal advice.

## What this notice covers

GrowthMap is local-first. Desktop project data, including the project SQLite database, is stored in the local desktop workspace and is not sent to the Production Activation API as part of normal project use.

## Activation and purchases

To activate a Personal entitlement, the activation service may process an activation or license code (or entitlement reference), device public identity/installation identity, nonce/proof material, and necessary protocol metadata. Service security and operational logs may include IP address and related security metadata. Whop is an independent purchase processor; its handling of purchase data is governed by its own notices and checkout terms.

## Support

Support handles information a user voluntarily provides for a support request. Never send passwords, payment credentials, private keys, activation codes, or a complete project database. If diagnosis requires project-shaped evidence, provide only a minimal redacted reproduction or export that you explicitly choose to share.

## Limits

This notice does not promise absolute security, a fixed retention period, particular cross-border processing arrangements, or a legal basis that has not been reviewed. Back up local project data before destructive actions. Questions or corrections may be submitted through the channels in [SUPPORT.md](SUPPORT.md).
